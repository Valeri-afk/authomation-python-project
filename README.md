# Python Automation Roadmap

Практический маршрут от изучения Python до первых оплачиваемых задач и production-like backend/automation разработки.

## Последовательность

1. Python и CLI — быстрые прикладные программы.
2. Data Automation — API, parsing, validation, PostgreSQL, scheduling, notifications.
3. Browser Automation — Playwright и разрешённые web-workflows.
4. FastAPI — automation engine как backend service.
5. Deployment — Linux, Docker, VPS, reverse proxy, HTTPS, logs.
6. Первый заработок — упаковка услуг, реальные задачи и параллельный поиск работы.

## Главный принцип

Не строить большой проект ради обучения. Каждый этап заканчивается работающим результатом и отвечает на вопрос: какую реальную проблему я теперь умею решать?

После этапа 02 уже можно проверять рынок на маленьких задачах. После этапов 04–05 проекты можно использовать как портфолио для junior backend/automation вакансий.
